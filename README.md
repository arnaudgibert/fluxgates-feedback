# Fluxgates - feedback & bug reports

This repo is where you report bugs in **[Fluxgates](https://store.steampowered.com/app/YOUR_APPID)**
and where its privacy note lives. It holds no game code - Fluxgates is made by
one person and the source stays private.

## Report a bug

**[Open an issue →](https://github.com/arnaudgibert/fluxgates-feedback/issues/new)**
(the same button as **Report a bug** in the game's hub).

Useful to include, in whatever order it comes out:

- **What happened**, and what you expected instead.
- **The build version** - Settings → About, e.g. `0.4.2 (a1b2c3d)`. Bugs get
  fixed against a specific build; without this I'm guessing.
- **Where you were** - which room, act, heat level, and any pact modifiers.
- **A screenshot**, if it's something you can see.
- **Your install ID** (Settings → Data) _only_ if the report is about telemetry
  or a crash - it's what ties a crash report to your issue. It is not needed
  otherwise.

Search the open issues first; a "same here, on build X" comment on an existing
report is more useful than a second copy of it.

## What I promise

I read everything here, and I go through new issues **once a week**. I don't
promise a reply to every one, and I don't promise a fix - but nothing goes
unread, and patch notes name the reports they fixed.

Feature requests are welcome as _problems_: tell me what got in your way, not
which button to add. That's the version I can actually solve.

## Balance complaints

Say them anyway - but know that they go to the data, not straight to the
backlog. "Act 3 is impossible" is a hypothesis I check against the anonymous run
statistics before changing a number, because loud feedback tracks frustration
rather than the actual difficulty curve.

## Privacy

[**privacy.md**](privacy.md) - what the game sends if you opt in, what it never
sends, and how to have your data deleted. Short version: off by default, no
accounts, no ads, nothing you type.
